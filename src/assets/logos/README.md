# Logos

Drop a logo file here and the site uses it everywhere that tool or app appears: Browse tools, results, the stack map, Stack Snap, the tool drawer and My plan. No code changes needed. Rebuild (`npm run build`) or restart `npm run dev` after adding files.

- Name the file exactly as listed below. `.png`, `.svg`, `.jpg` or `.webp` all work (the name before the dot is what matters).
- Square works best, at least 128×128, on a transparent or white background.
- Anything without a file keeps its colored initials.
- Tools built into an app borrow that app's logo until they get their own: `jobber.png` also covers Jobber AI Receptionist, `square.png` covers Square AI phone ordering, `quickbooks.png` covers QuickBooks AI agents, `housecall-pro.png` covers both Housecall Pro tools, `glossgenius.png` and `vagaro.png` cover their AI tools, and `maple.png` covers Maple Pro and Maple Voice.
- Only use real company logos you have permission to use (many vendors publish a press or brand kit with usage rules).
